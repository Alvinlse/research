\section*{概要}
高負荷のHPC/GPUクラスタでは資源利用率とSLA遵守がトレードオフの関係にあり，
その本質は「どのジョブの安全マージンを削るか」という配給問題である．
本稿では，需要側と供給側のLLMエージェントがマージンと予約を交渉し，
決定はオークション（配給）とILP（実行可能性保証）が行うスケジューラ
PINS を提案する．設計原則は一貫して「LLMは推論・説明し，決定論的機構が決定する」である．
Alibaba v2020 実トレースの再生実験（32シード対応比較）において，
（1）Stage-1 の使用量予測に基づく適正要求は利用者申告を全指標で有意に上回り，
交渉@qwen2.5:3b は SLA違反 $-4.9$〜$-6.8$pt\sig，prod層SLA $-5.2$〜$-6.8$pt\sig を
同時達成する．（2）交渉方式は EASY バックフィル（オラクル実行時間つきでも）と
表形式Q学習を大差で上回る．（3）有界譲歩プロトコルにより 3b の小規模モデルが
14b と統計的同等（TOST）となり，モデル規模を機構が代替する．
（4）利用者別予算と係争ティック課金により虚偽申告の利得は統計的にゼロとなり，
LLM利用者エージェントの自発的な搾取行動も正直申告へ反転する．
全割当は両エージェントの自然言語による正当化を伴い，RLにない監査可能性を持つ．

\section{はじめに}
AI・科学技術計算ワークロードはバースト的かつ異質であり，静的なバッチスケジューラ
では資源利用率とサービス品質（SLA遵守率）の両立が難しい．利用率を押し上げると
SLA違反率も上がる——この緊張関係は，飽和領域では\textbf{全ジョブに安全マージンを
与えることが物理的に不可能}であることに由来する．すなわちサービス品質を実際に
決めているのは「\textbf{誰の安全マージンを削るか}」という配給の意思決定であり，
古典的スケジューラはこれを盲目的に（FCFSや固定優先度で）行っている．

本研究はこの配給を\textbf{二者交渉}で行う．ジョブ側の私的情報（緊急度・締切・
予測需要の不確かさ）を持つ\textbf{需要エージェント}と，クラスタ側の私的情報
（実容量・将来負荷・公平性）を持つ\textbf{供給エージェント}——意図的に非対称な
目的を持つ2つのLLM——が，根拠つきの要求と予約を交換する．ただしLLMの自由対話に
決定させると保証が消えるため，決定は決定論的機構が行う：
\textbf{コミット型オークション}が交渉結果を清算して配給し，
\textbf{ILP}がノード配置の実行可能性を保証する．
一文で言えば「\textit{LLMは不確かさの下で価値を推論し，オークションが配分を決定し，
ILPが実行可能性を保証する}」．

主な貢献は以下の通りである．
\begin{enumerate}
  \item \textbf{三層機構の設計と実装}：二者LLM交渉（有界譲歩プロトコル，収束保証）
        → コミット型オークション清算 → ILP配置保証．
  \item \textbf{予測が要求を適正化}：利用者申告（中央値でGPUの50\%を要求，実使用
        中央値は0.22\%）を Stage-1 使用量予測（GBT分位点）に置換すると，
        全プール・全方式でSLAが有意に改善（申告比 $+9$〜$+17$pt\sig の無駄を回収）．
        交渉と予測は補完的で，交渉@3bは床（交渉なし規則）に対し全ヘッドライン指標で
        同時に勝つ最初の世界となる．
  \item \textbf{機構がモデル規模を代替}：譲歩プロトコルの下で 3b ≡ 14b（TOST等価），
        能力の閾値は 1.5b--3b の間，命令追従性が規模より効く（gemma2:2b は通過，
        llama3:8b は競合時に有意に悪化）．
  \item \textbf{インセンティブ層}：利用者別予算＋係争ティック課金により虚偽申告の
        利得が統計的にゼロ化．自己利益のみを指示されたLLM利用者エージェントは
        無課金機構を\textit{自発的に}搾取するが，同じ課金で正直申告と等価になる．
  \item \textbf{境界の測定}：古典基線（EASY・表形式Q学習）との比較，割当量子
        （whole-GPU vs 1/4量子）のコスト，第二トレースでの適用限界を対応比較・
        95\%信頼区間つきで報告する．
\end{enumerate}

\section{関連研究}
\paragraph{LLM駆動スケジューリング}
LLMsched \cite{llmsched} は単一LLMの提案をILPが修復する reason-then-guarantee 構成で
Kubernetes 比 JCT $-23.7\%$ 等を報告した．本研究はこの背骨を継承しつつ，単一提案者を
二者交渉に分割する：単一LLMは需要対供給のトレードオフをプロンプト内で不可視に
潰すのに対し，二エージェントはそれを明示化・監査可能にする（実測でも単一LLM基線は
全規模で交渉に劣る，\S\ref{sec:eval}）．
\paragraph{学習ベーススケジューラ}
DeepRM/Decima 系のDRLは割当方策を学習するが，ブラックボックスであり分布シフトに
弱い．本研究は同一インタフェース上の表形式Q学習を弱い代表として測定し，
リターン分散が行動効果を支配する構造的困難を示す（\S\ref{sec:eval}）．
\paragraph{マレアビリティ}
実行時のジョブ伸縮は20年以上研究されつつ本番系では未活用である \cite{tarraf2024}．
本研究の弾力的部分割当はこの前提の上に立ち，その帰結（全か無かのEASYが不利になる）
も正直に報告する．
\paragraph{メカニズムデザイン}
均一価格オークションや予算制約による正直申告の誘導は古典的主題である．本研究の
貢献は，宣言的なLLMエージェントを含む閉ループでの実測（best-response試験）である．

\section{PINS の設計}
\subsection{全体像}
\todo{図1: パイプライン図（需要LLM⇄供給LLM → オークション → ILP，ゲート付き）}
高速パス（規則ベース）が既定で動き，「待ち時間が交渉コストを超え，かつ価値がある」
ジョブのみ交渉へエスカレートする．交渉はタイムボックス化され，不収束時は高速パスへ
フォールバックする（交渉は改善専用であり，クリティカルパスに乗らない）．

\subsection{二者交渉と有界譲歩プロトコル}
需要エージェントは Stage-1 予測区間 $[P10,P90]$ の幅から安全マージンを，
供給エージェントは到着予測と rigid ジョブ比率からヘッドルーム予約を提案する．
交換は自由対話ではなく\textbf{有界譲歩プロトコル}（ラウンド上限つきの構造化
オファー交換）で行われ，停止性が証明可能である．LLMの出力は
「順序クラス・ヘッジ水準・予約水準＋一行の正当化」に限定され，数値の最終決定は
機構が行う．

\subsection{コミット型オークションとILP}
毎ラウンド再入札する価値最大化オークションはGPUを薄く分散させ再順序付けを起こし，
貪欲FIFOにすら負ける（Exp 9--10）．PINSは\textbf{到着時に一度だけ入札し，優先度を
凍結し，完走まで直列化する}コミット型清算を用いる．ノード配置は ILP が count+node を
同時に解き，断片化を除去する——LLMの攻撃的なマージン要求を「安全」にするのは
この保証層である（Exp 25）．

\subsection{Stage-1: 使用量予測}
利用者申告は実使用をほぼ追跡しない（中央値50\% vs 0.22\%，$\rho=0.23$）．
PINSは申告をLLMに数値予測させる代わりに——LLMは較正された数値予測者として
一貫して敗北する（Exp 1, 19--21）——GBT分位点回帰で実使用量 $P10/P50/P90$ を予測し，
$P50$ を要求の基礎，区間幅を prod 層ヘッジ（newsvendor 的 prod-p90 規則）に用いる．

\subsection{インセンティブ層}
コミット型オークションは申告クラスを信頼するため，虚偽申告（best-effort が
critical を名乗る）で保護が崩れる（Exp 13）．対策は\textbf{利用者別予算}（ジョブは
財布を共有）＋\textbf{係争ティックのみの自己請求課金}＋支払不能時のポートフォリオ
降格である．鍵は虚偽のコストが\textit{同一利用者の}prodジョブに内部化される点にある．

\section{評価}\label{sec:eval}
\subsection{実験設定}
Alibaba cluster-trace-gpu-v2020 の606kジョブから窓を抽出し，到着・所要・需要を実データ
のまま再生する（\texttt{trace\_replay}）．プール$\{4,6,8\}$GPU（スケール実験は30GPU/500ジョブ），
1/4GPU量子，32シード対応比較（\sig は95\%CIが0を除く）．LLMはローカルOllama
（qwen2.5:0.5b--14b, gemma2, llama3）；比較arm間で窓とシードを完全対応させる．
基線：交渉なし規則（床），単一LLM（両目的を1プロンプトに持つ），孤立エージェント，
EASYバックフィル，表形式Q学習．\todo{表: 実験設定サマリ}

申告要求を Stage-1 P50 使用量予測に置換すると，交渉@3bでSLA違反 $-9.2$〜$-17.0$pt\sig，
飽和時 slowdown は半減する．予測の残存誤差はオラクル比 $+2$〜$+6$pt を残すが，

\subsection{主結果2: 基線三角形}
競合下（pool 6/8）で
$\text{交渉@3b} \ge \text{床} > \{\text{EASY}, \text{Q学習}\}$ が成立する．
EASYは予測実行時間で床に $+11.7$pt\sig 劣り，オラクル実行時間でも交渉に勝てない
（交渉@3b $-$ easy-pred: SLA $-12.5$\sig，prodSLA 最大 $-21.0$\sig）．
実行時間予測誤差はEASYに5--10ptのコストを課す——本システムで実行時間予測の質が
効く唯一のスロットである．表形式Q学習は同一インタフェース・同一情報でも床に
$+7.0$〜$+17.2$pt\sig 劣る：エピソードリターンの分散が行動効果を支配し，
実現可能なサンプル数では信用割当が成立しない（DRLをスコープ外とする実測根拠）．

\subsection{主結果3: 機構がモデル規模を代替する}
prod層保護（床比 $-4$〜$-8$pt\sig）は rule ≈ 3b ≈ 7b ≈ 14b で統計的に区別できず
（TOST等価），無ブレーキの単一LLMのみが規模を必要とし全規模で負ける．
モデル梯子では床は 0.5b と 1.5b の間，gemma2:2b は族を跨いで通過，
llama3:8b は競合時に有意に悪化する——効くのは規模でなく命令追従性である．
500ジョブ規模では孤立エージェントがSLAを悪化させ単一LLMは崩壊する中，
交渉@3bのみが両指標を改善する（$-1.7$\sig/$-6.2$\sig）：スケールするのは
ヘッジではなく\textbf{二者プロトコルそのもの}である．

\subsection{主結果4: インセンティブ}
無課金機構では虚偽申告が $-14$〜$-24$\sig の純利得を生む．利用者別予算120＋係争
ティック課金の下で利得は全プールで統計的ゼロとなる（虚偽のコストは同一利用者の
prodジョブに $+15$\sig として着地する）．「自ジョブを最大化せよ」とだけ指示された
LLM利用者は無課金機構を\textit{促されずに}搾取し（3bは14bより強く搾取），
同じ課金で両者は正直申告と等価になる——14bの正当化は財布の外部性を明示的に引用する．
抑止は\textbf{可読な規則}を通じて働き，これがRLに対する解釈可能性の主張の実測形である．
正直世界の配給コストは prodSLA $+3$〜$+9$pt（抑止と配給のフロンティア＝運用者の
公平性メニュー）．

\subsection{境界}
（i）\textbf{割当量子}：whole-GPU 割当は世界そのものに約10 SLA pt / 完了70ジョブの
パッキング損を課し，どの方策も内部からは回収できない——1/4量子という機構側の修正が
任意の方策側の修正を支配する．（ii）\textbf{第二トレース}（MIT Supercloud, whole-GPU
1--2スロット）：ヘッジがプールの25--100\%を占める粗さでは交渉が害になる；殺すのは
whole-GPU性ではなくプール比の量子粗さである．（iii）交渉の全レバーはスラックを
要する——飽和では何も効かない．

\section{考察と限界}
締切・緊急度・層は合成レシピであり，トレース再生世界は既存割当をプリエンプトしない
（自由なマレアビリティを仮定した主張はしない）．EASYとの差の大部分は弾力的付与
対全か無か付与のモデル差である．匿名課金は「全員が嘘つき」の世界を救えない．
LLM推論の実時間コストはゲートにより待ち時間の影に隠れる設計だが，本稿の評価は
シミュレーション時計上で行った．\todo{肯定的な含意（運用者がプロンプトで供給方針を

\section{おわりに}
「LLMは推論・説明し，決定論的機構が決定する」という分業は標語ではなく，
形状対算術・クラス対重み・ヘッジ水準対GPU数・申告対清算——全層で実測上最適な
分割だった．二者交渉＋コミット型オークション＋ILPは，実トレース上で古典基線と
学習基線を上回り，小規模モデルで足り，虚偽申告に頑健で，全割当に監査可能な
正当化を残す．今後の課題は実クラスタ（A100）上の閉ループ検証である．
